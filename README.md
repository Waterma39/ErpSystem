# 企業資源規劃系統（ERP 系統）

## 專案簡介
本專案為一個企業資源規劃與資料庫總覽系統，旨在提供統一的資料庫探索、查詢與視覺化儀表板，支援動態檢視所有資料表內容。

## 技術堆疊（Tech Stack）
- 後端框架：點網 10 網頁應用程式介面（.NET 10 Web API）
- 資料庫管理：結構化查詢語言伺服器（SQL Server / Entity Framework Core）
- 前端與介面：超文字標語與萬能資料庫總覽儀表板（HTML5 / JavaScript Dashboard）

## 主要功能
- 動態資料庫探索：自動抓取並建立資料庫內所有資料表的 API 查詢路由。
- 視覺化儀表板：提供一頁式網頁介面，點擊即可即時檢視與對照各資料表內容。
